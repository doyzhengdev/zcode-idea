## 为什么改

复核发现三处问题：

1. **与实际不符**：原文写"薄包首次打开按需下载"，但薄包的 runtime 下载链路目前不可用
   （默认地址是占位域名、CDN 上没有 runtime），而 0.0.6/0.0.7 发布的是完整包。
   照原文描述，用户会以为可以省流量，实际会遇到启动失败。
2. **缺关键限制**：共用 `~/.zcode` 时与桌面客户端同时运行会 SQLite 锁冲突，这是用户最容易
   踩的坑，之前只写在内部 `INVARIANTS.md` 里。
3. **术语过深**：`ideHost=1` 门控对使用者没有意义，改成描述效果即可；实现细节留在内部文档。

## 验证
