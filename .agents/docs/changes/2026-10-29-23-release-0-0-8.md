# 2026-10-29 · 发布 0.0.8（README / 元数据更新）

- **范围**：版本号与发布（full package）
- **触发**：用户要求把 0.0.7 之后的文档与 npm 元数据改动发布出去
- **提交**：working tree

## 源码改动

| 文件 | 类型 | 说明 |
|---|---|---|
| `package.json` / `scripts/npm/package.json` / `scripts/npm/package-lock.json` | 修改 | 版本 0.0.7 → 0.0.8 |

插件 Kotlin 代码与 0.0.7 相同。本次发布的实质内容是 npm 页面元数据：README 重写（定位、
适合谁用、运行机制、明确不支持项）、`description` 与 17 个 `keywords`（见 `-15` ~ `-22`）。
npm 页面的描述/关键词/README 都是发布时快照，不发版就看不到。

## 行为变化

- 安装包版本 0.0.8，插件功能与 0.0.7 一致。
- npm 搜索可见性提升（IDE 名、`z.ai`、`glm`、`ai-coding` 等关键词生效）。

## 验证

- 构建：`--apply --bundle-runtime` → `zcode-ide-0.0.8.zip`，49,965,147 bytes，
  sha256 `772cd018e97521fd44b7654c3e8c6a81d252d8aa5c821397190c3b5a22c35de3`，含 runtime。
- 本地安装：`npm pack` 39.5 kB / 16 文件；`npx --package ./zcode-idea-0.0.8.tgz -- zcode-idea update --zip …0.0.8.zip --target <临时目录> --no-launch` → 5381 文件、`runtime/web/index.html` 就位、识别为完整包。
- 发布：上传七牛 5 个对象（zip 49.9MB / 8.3s）；`/0.0.8/manifest.json` 的 size/sha256 与本地一致，zip `HEAD` 200。
- npm：`npm publish` 返回 **HTTP 202（后台处理）**，随后轮询确认
  `zcode-idea@0.0.8` 可查、`dist-tags.latest = 0.0.8`。

## 风险 / 后续

- 国内镜像（npmmirror）同步可能滞后，旧版本会被继续返回（见 `-13` 的绕过写法）。
- 稳定指针仍受七牛域名级缓存影响；版本化清单不受影响。
- 仍是完整包（47.6MB）；恢复薄包的前提见 `-10`。
