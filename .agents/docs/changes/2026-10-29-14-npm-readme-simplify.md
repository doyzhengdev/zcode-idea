| 文件 | 类型 | 说明 |

## 为什么改

原 README 同时承担用户手册（快速使用/常用参数/进程处理/镜像延迟）与维护者手册
（分发与版本/发布命令），对终端用户来说信息过载，且命令细节容易随实现变化而过期。
现在：

- 功能与流程图说明"这个安装器做什么、怎么做"，稳定不易过期；
- 具体命令、参数、排障、镜像绕过、发布流程留给 `--help`、变更记录与
  `BUILD-AND-DEPLOY.md`，避免多处维护。
