## 为什么改

实测数据不支持"功能 99%"的说法：

- 代码层面接近 100% 官方：官方 ts/tsx 文件 5,615 个、约 112.3 万行，我们只改 19 个文件、
  +424 / −67 = 491 行（**0.044%**）；
- 功能层面有明确缺口：`IDE-VS-DESKTOP.md` 里标注了多项【不支持】（远程工作区、Docker、
  WSL/SSH、Computer Use、内置浏览器侧栏）与一大批被隐藏的桌面专属入口。

继续写"99% 功能"会让用户装完发现入口缺失而质疑。改成"代码 0.04% 改动 + 不支持项清单"，
卖点仍然成立，且可被读者用官方仓库核对。
